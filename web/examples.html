Code for the JavaScript mode of the test page: the body of an async function that builds expressions in JavaScript, has the kernel evaluate them, and works on the results. Run shows the output under each example; Open in editor puts the code in the test page's editor, to change it there.

the expression Sin[x]; W.x is the variable x, capitalized names are built-in symbols
await wl(expr)
evaluates and gives the result; a string, or wl`…${value}…`, is Wolfram Language text

evaluates and shows the result: typeset math or a picture
toJS(result)
numbers, booleans, arrays and objects from a result
